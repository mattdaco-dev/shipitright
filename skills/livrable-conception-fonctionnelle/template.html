Modèle conceptuel des données métier

Les objets que le métier manipule, leurs attributs clés au format nom [type métier] et leurs relations. Aux deux bouts de chaque relation, la cardinalité côté objet : combien de cet objet pour un de l'autre (0:1, 1:1, 0:n, 1:n). Pas de clés techniques ni de types SQL : le modèle physique revient à l'architecte.
