# Format examples

The filled examples that were used to settle, with the human, the format of each deliverable. Content
taken from the pilot project "Réservation de salles", written by the PO to judge the rendering: they
are not the deliverables of the project, which the team still has to produce.

The example is a French project: `.team/project.json` holds `{ "language": "fr" }`, so the visible
content of the pages is in French while codes, paths, ids, meta names and values follow the plugin's
English names.

Open `docs/index.html` in a browser: it is the dashboard, as in a project, and it leads to the other
examples (the epics through the backlog, the workstream analysis through the analysis inventory). An
agent that produces a deliverable can take it as a model for the rendering and the level of detail;
the skill's template stays the starting point.

The commands quoted here run from the root of the ShipItRight repository. The example's
`foundations/` folder keeps the old place of foundations, next to `docs/`; in a project, a foundation
created for it goes into `.team/foundations/` (`team/conventions/foundation.md`).
