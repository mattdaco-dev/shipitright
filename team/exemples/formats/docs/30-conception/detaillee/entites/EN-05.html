EN-05 : Réservation

L'occupation d'une salle sur un créneau par un titulaire. Point de convergence de RG-01 : la table refuse elle-même tout chevauchement entre réservations actives d'une salle.

CREATE TABLE reservations (
  id                INTEGER PRIMARY KEY,
  salle_id          INTEGER NOT NULL REFERENCES salles(id),             -- EN-03
  titulaire_id      INTEGER NOT NULL REFERENCES employes(id),           -- EN-01
  serie_id          INTEGER NULL REFERENCES series(id),                 -- EN-06 ; nul : réservation
                                                                        -- ponctuelle (RG-06)
  jour              TEXT NOT NULL CHECK (jour = date(jour))
                    CHECK (strftime('%w', jour) NOT IN ('0','6')),       -- RG-02 jours ouvrés
  debut_min         INTEGER NOT NULL
                    CHECK (debut_min % 15 = 0 AND debut_min >= 480),      -- RG-02
  fin_min           INTEGER NOT NULL
                    CHECK (fin_min % 15 = 0 AND fin_min <= 1140
                           AND fin_min > debut_min AND fin_min - debut_min <= 240),  -- RG-02
  statut            TEXT NOT NULL DEFAULT 'active'
                    CHECK (statut IN ('active','annulee')),      -- « passée » n'est pas stockée
  motif_annulation  TEXT NULL CHECK (length(motif_annulation) <= 200),  -- RG-07, RG-08
  annulee_le        TEXT NULL,                                          -- ISO 8601 UTC
  annulee_par       INTEGER NULL REFERENCES employes(id),               -- RG-07, RG-11 ; autre que le
                                                                        -- titulaire : EP-11 montre le motif
  presence_le       TEXT NULL,                                          -- release R3, EP-20 ; ISO 8601 UTC
  cree_le           TEXT NOT NULL,                                      -- ISO 8601 UTC
  CHECK ((statut = 'annulee') = (annulee_le IS NOT NULL))
);
-- contrôle de conflit (TR-02, déclencheurs), occupation d'une salle (EP-06), recherche (EP-07)
CREATE INDEX reservations_salle_jour ON reservations(salle_id, jour, statut);
-- occupation toutes salles (EP-06), statistiques (TR-05)
CREATE INDEX reservations_jour ON reservations(jour, statut);
-- annulation d'une série (EP-13)
CREATE INDEX reservations_serie ON reservations(serie_id);
-- mes réservations (EP-11)
CREATE INDEX reservations_titulaire ON reservations(titulaire_id, jour);

-- RG-01 : aucun chevauchement entre réservations actives d'une salle, bornes strictes (ADR-0002,
-- CF-61) ; 09:00-10:00 puis 10:00-11:00 passe, 09:30-10:30 est refusé. Filet du contrôle de TR-02.
CREATE TRIGGER reservations_no_overlap_insert BEFORE INSERT ON reservations
WHEN NEW.statut = 'active' AND EXISTS (
  SELECT 1 FROM reservations r
  WHERE r.salle_id = NEW.salle_id AND r.jour = NEW.jour AND r.statut = 'active'
    AND NEW.debut_min < r.fin_min AND NEW.fin_min > r.debut_min)
BEGIN SELECT RAISE(ABORT, 'CRENEAU_PRIS'); END;
-- même contrôle à la mise à jour, hors la ligne elle-même : sert la modification (EP-19, release R2) ; une
-- annulation rend la ligne inactive et ne déclenche rien
CREATE TRIGGER reservations_no_overlap_update
BEFORE UPDATE OF salle_id, jour, debut_min, fin_min, statut ON reservations
WHEN NEW.statut = 'active' AND EXISTS (
  SELECT 1 FROM reservations r
  WHERE r.id <> NEW.id AND r.salle_id = NEW.salle_id AND r.jour = NEW.jour AND r.statut = 'active'
    AND NEW.debut_min < r.fin_min AND NEW.fin_min > r.debut_min)
BEGIN SELECT RAISE(ABORT, 'CRENEAU_PRIS'); END;

Règles hors de la base

  • RG-03 (pas dans le passé, pas d'annulation d'une réservation commencée) dépend de l'heure courante : elle ne peut pas être une contrainte. Elle vit dans l'objet de valeur Creneau et dans la transition d'annulation (TR-06), avec l'horloge injectée (CF-62).
  • RG-08 (pas de réservation sur une salle désactivée) et RG-11 (annulation par le titulaire ou le gestionnaire) portent sur d'autres lignes ou sur la session : contrôlées par TR-02 et TR-06.
